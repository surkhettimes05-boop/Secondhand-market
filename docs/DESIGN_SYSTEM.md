# Design system baseline

The source of visual direction is [the implementation plan](IMPLEMENTATION_PLAN.md). Implemented tokens live in `src/app/globals.css`.

## Composition

- Ink typography, indigo actions, off-white canvas and natural illustrative photos.
- Photo-led editorial home; functional search filter rail; detail page with useful cost disclosures.
- Three specific category treatments, consistent pricing hierarchy and restrained elevation.
- Screen widths: 360, 390, 560, 760, 900, 1100 and 1440 px.
- Layouts use spacing and subtle borders rather than a repeated marketing-card template.

## Components

Brand, primary/secondary buttons, form controls, category entries, listing cards, filter chips, informational panels, posting stages, draft review and empty states.

## Content and persuasion

Highlight location, honest condition and separate costs. Keep contact context-specific in later real inventory. Sample inventory remains labelled. No fabricated reviews, user counts, scarcity or authenticity badges.

## Review still required

Actual browser screenshots, contrast audit, keyboard/screen-reader checks, Nepali typography review and local usability sessions. Google Fonts is temporary; self-host licensed fonts before production.

## Design decisions

The full preview avoids artificial social proof. Its primary real actions are exploration, local saving and local draft creation. Server publishing and seller contact are future phases and the interface says so.
